# Security policy

Please use this repository's private GitHub Security Advisory workflow to report a suspected vulnerability. Include the affected contract and function, a minimal reproduction, the expected impact, and any assumptions needed to trigger it.

Do not publish an active exploit, private key, seed phrase, RPC credential, unrevealed pack content, random salt, or decryption key in a public issue.

The deployed contracts and exact source-verification links are listed in [README.md](README.md). Verify every address before testing or interacting with mainnet.
